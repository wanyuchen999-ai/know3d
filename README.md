# 智观3D · 学科交互模型库

> 把抽象的知识,变成可以**转着看、点着学**的三维模型。
> 面向医学生的系统解剖学骨学库为核心,扩展地理 / 天文 / 化学 / 生物多学科。
> **完全本地运行、无需注册、不上传任何数据。**

---

## 一分钟上手

1. 双击 **`启动.bat`**(Windows;只需已安装 Python,无需其它依赖)
2. 浏览器自动打开 `http://localhost:8765`
3. 选一个模型卡片进入查看器

> 也可以手动启动:`python serve.py`
> 其它系统(Mac/Linux)直接运行 `python3 serve.py` 即可。

---

## 它能做什么

### 🩺 医学 · 系统解剖学(核心)

- **真实数据**:全部骨骼模型来自日本 DBCLS 的 **BodyParts3D**(基于成人 CT 重建,CC BY-SA 2.1 JP 开源许可),不是手绘示意。
- **40 块单骨模型**:额骨、蝶骨、筛骨、下颌骨、寰椎、枢椎、胸椎、腰椎、骶骨、胸骨、肋、锁骨、肩胛骨、肱骨、桡骨、尺骨、腕骨、髋骨、股骨、髌骨、胫骨、腓骨、距骨、跟骨……每块都可全方位旋转、缩放。
- **颅(14 块颅骨拼接)+ 全身骨骼(68 块)**:每块骨可单独点击、高亮、隔离显示;底部骨块列表一键控制。
- **考点级标注**:颅底内面观 19 个热点(枕骨大孔、颈静脉孔、内耳门、棘孔、卵圆孔、破裂孔、圆孔、视神经管、垂体窝、鸡冠、翼点,双侧结构左右各一);胸椎、髋骨、肱骨、股骨、下颌骨按实验报告填图结构逐一定位标注。
- **知识卡**:点击任意骨/结构,显示中文名、拉丁/英文名、简介、主要结构、★本科考点、临床联系、记忆口诀(知识库覆盖 44 个词条,按《系统解剖学》本科要求整理)。
- **视角预设**:每块骨有"前面观/侧面观/上面观/颅底内面观(自动隐藏颅顶)"等标准解剖学视角,一键飞达。
- **📝 自测模式**:按考点名称点击对应标注,自动判分(答错时绿色高亮正确位置),适合实验考前突击。
- **📷 截图**:一键保存当前画面 PNG,可直接贴进实验报告。

### 🌍 地理 · 地球仪
- 249 个国家/地区点选:中英文名、国旗、首都、人口、面积、大洲、简介;
- 点击后国家金色高亮 + 相机飞至该国;悬停显示国名;七大陆预设视角;自动自转。

### 🪐 天文 · 太阳系
- 八大行星 + 太阳,公转动画(可暂停)、土星环、轨道线;
- 点击行星:距日距离、公转周期、卫星数、温度、科普看点;相机聚焦飞行。

### ⚗️ 化学 · 分子结构
- 16 种常见分子(水、甲烷、苯、葡萄糖、乙醇、尿素……)的球棍模型,按标准键长键角计算;
- 点击原子 → 元素信息(序数/质量/说明);点击键 → 键级与键长。

### 🔬 生物 · 动物细胞
- 可点击的三维模式图:细胞膜、细胞核(核仁/染色质)、线粒体(带嵴)、粗面/滑面内质网、高尔基体、核糖体、溶酶体、中心体。

### 🦴 骨学总论 · 骨的构造
- 长骨剖面模式图:骨密质、骨松质(骨小梁纹理)、骨膜、红/黄骨髓、骨髓腔、关节软骨、骺线、滋养孔,9 个编号考点。

### 🤖 AI 深入问答
- **离线知识库模式(默认,零配置)**:对当前模型/选中结构自动检索内置考点作答;
- **云端大模型(可选)**:点 ⚙️ 填入你自己的 API Key(预设智谱 glm-4-flash / DeepSeek / OpenAI 或任意 OpenAI 兼容接口),提问自动附带"当前模型 + 选中结构"上下文。Key 仅存本机 localStorage。

### 📥 导入自己的模型
把任意 `.glb` / `.gltf` / `.obj` 拖进查看器即可加载(纯本地解析,不上传)。

## 操作方法

| 操作 | 效果 |
|---|---|
| 左键拖动 | **全方位旋转**(上下左右任意角度,无限制) |
| 滚轮 | 缩放(可贴近细看孔裂) |
| 右键拖动 | 平移 |
| 单击骨头/标注圆点 | 打开知识卡 |
| 双击某块骨(组装模型) | 隔离单独显示;再双击空白处恢复 |
| 顶部按钮 | 重置视角 / 自动转 / 标注开关 / 自测 / 截图 / AI |

```
know3d/
├─ 启动.bat / 停止.bat        # 一键启动/停止
├─ serve.py                   # 零依赖本地服务器(自动开浏览器)
├─ index.html                 # 模型库首页
├─ viewer.html                # 3D 查看器
├─ css/app.css
├─ js/
│  ├─ catalog.js              # 模型目录(所有卡片)
│  ├─ viewer.js               # 查看器核心(旋转/拾取/热点/AI面板)
│  ├─ ai.js                   # AI(内置知识库 + 云端可选)
│  ├─ modules/                # 各学科模块
│  │  ├─ anatomy.js  globe.js  solar.js  molecule.js  cell.js  bone-structure.js
│  └─ lib/                    # three.js 等本地化依赖(离线可用)
├─ models/anatomy/            # 59 个骨骼 GLB + manifest.json
├─ data/
│  ├─ anatomy/kb.json         # 44 条骨学知识卡
│  ├─ anatomy/hotspots/       # 考点标注坐标(颅/胸椎/髋/肱/股/下颌)
│  ├─ geo/                    # 国家边界 + 249 国中文资料
│  └─ chem/                   # 16 种分子几何数据
└─ tools/
   ├─ downloads/              # BodyParts3D 原始数据(143MB,可删)
   ├─ prepare_models.py       # OBJ→清洗→减面→GLB 管线
   ├─ build_geo.py            # 生成国家中文数据
   └─ gen_molecules.py        # 生成分子数据
```

## 常见问题

- **打开是空白/加载失败**:必须通过 `启动.bat`(本地服务器)访问,直接双击 html 会因浏览器安全限制无法读取模型。
- **AI 一直"内置知识库"**:正常,零配置即用;想用大模型就在 AI 面板 ⚙️ 里填 Key。
- **女性骨骼**:BodyParts3D 官方数据集为成人男性;女性骨盆差异(耻骨下角 90~100°、骨盆宽短等)已在髋骨知识卡的"男女骨盆差异"考点中讲解。
